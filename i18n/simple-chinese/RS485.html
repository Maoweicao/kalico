    RS485 伺服支持¶

    本文档介绍 Kalico 对 RS485 伺服驱动器的支持，包括 Modbus RTU 和自定义协议。RS485 允许通过半双工串行总线使用带位置反馈的工业伺服电机。

    概述¶

    RS485 是串行通信的物理层标准。与步进/方向信号不同，RS485 通过共享总线发送位置指令并接收实际位置数据。Kalico 支持在 RS485 上运行的多种协议：

    • Modbus RTU — 工业标准协议（CiA 402 寄存器映射）
    • UART 透传 — 原始字节级通信，用于自定义协议
    • 自定义协议 — 用户编写的 Python 类，用于厂商私有协议

    硬件要求¶

    RS485 适配器¶

    需要一个连接到主机的 RS485 适配器。常见方案：

    • FTDI FT232RL + MAX485：通过 CBUS 引脚自动方向控制
    • CH340 + MAX485：通过 RTS 信号控制方向
    • USB 转 RS485 转换器：带自动方向控制的现成适配器

    接线¶

    主机 ─── USB 转 RS485 ─── RS485 总线 ─── 伺服驱动器
         │                │
         │  A ─────────── A（数据-）
         │  B ─────────── B（数据+）
         │  GND ───────── GND
         │
         └── 总线两端各安装 120Ω 终端电阻

    伺服驱动器¶

    任何支持 Modbus RTU 或自定义 RS485 协议的伺服驱动器：

    • 雷赛 ES/EC 系列 — Modbus RTU，自定义寄存器映射
    • 台达 ASDA 系列 — Modbus RTU
    • 松下 MINAS 系列 — Modbus RTU
    • 通用 RS485 伺服 — 通过 UART 透传

    配置¶

    Modbus RTU（默认）¶

    [rs485_stepper x]
serial_port: /dev/ttyUSB0
baud_rate: 9600
rs485_protocol: modbus_rtu
rs485_slave_id: 1
rotation_distance: 40
microsteps: 1
full_steps_per_rotation: 200
endstop_pin: ^PC1
homing_speed: 10.0
position_min: 0
position_max: 200

    UART 透传¶

    [rs485_stepper y]
serial_port: /dev/ttyUSB0
baud_rate: 115200
rs485_protocol: uart_passthrough
rs485_slave_id: 1
rs485_response_length: 8
rotation_distance: 40
microsteps: 1
full_steps_per_rotation: 200

    自定义协议（如雷赛）¶

    [rs485_stepper z]

    编写自定义协议¶

    要为你的伺服驱动器编写自定义协议，继承 klippy.extras.rs485.protocol 中的 RS485Protocol：

    # 文件：klippy/extras/my_servo_rs485.py
from klippy.extras.rs485.modbus_rtu import ModbusRtuProtocol

class MyServoProtocol(ModbusRtuProtocol):
    """MyServo RS485 驱动器的自定义协议"""

    # 寄存器地址（查看驱动器手册）
    REG_CONTROL = 0x0000
    REG_STATUS = 0x0001
    REG_TARGET_POS_L = 0x0010
    REG_TARGET_POS_H = 0x0011
    REG_ACTUAL_POS_L = 0x0012
    REG_ACTUAL_POS_H = 0x0013

    def set_target_position(self, position):
        pos_u = position & 0xFFFFFFFF
        self.write_register(self.REG_TARGET_POS_L, pos_u & 0xFFFF)
        self.write_register(self.REG_TARGET_POS_H, (pos_u >> 16) & 0xFFFF)

    def get_actual_position(self):
        lo = self.read_register(self.REG_ACTUAL_POS_L)
        hi = self.read_register(self.REG_ACTUAL_POS_H)
        pos = (hi << 16) | lo
        if pos >= 0x80000000:
            pos -= 0x100000000
        return pos

    def set_control_word(self, value):
        self.write_register(self.REG_CONTROL, value & 0xFFFF)

    def get_status_word(self):
        return self.read_register(self.REG_STATUS)

    def get_state_name(self):
        sw = self.get_status_word()
        if sw & (1 << 3): return "FAULT"
        if sw & (1 << 2): return "OPERATION_ENABLED"
        if sw & (1 << 1): return "SWITCHED_ON"
        if sw & (1 << 0): return "READY_TO_SWITCH_ON"
        return "UNKNOWN"

    然后在配置中引用：

    [rs485_stepper x]
rs485_protocol: custom
protocol_class: my_servo_rs485.MyServoProtocol
# ...

    协议接口¶

    自定义协议必须实现以下方法：

    方法 描述
    read_register(register) 读取寄存器，返回整数值
    write_register(register, value) 写入寄存器，值为整数
    set_target_position(position) 设置目标位置（编码器计数）
    get_actual_position() 获取实际位置（编码器计数）
    set_control_word(value) 设置驱动器控制字
    get_status_word() 获取驱动器状态字
    get_error_code() 获取错误码（可选）
    get_state_name() 获取可读的状态名（可选）

    Modbus RTU 寄存器映射¶

    默认寄存器映射使用标准 CiA 402 地址：

    寄存器 地址 描述
    控制字 0x6040 驱动控制
    状态字 0x6041 驱动状态
    目标位置 0x607A 位置指令（32 位）
    实际位置 0x6064 位置反馈（32 位）
    运行模式 0x6060 运行模式
    错误码 0x603F 错误代码

    可在配置中指定自定义寄存器地址：

    [rs485_stepper x]
register_control_word: 0x0000
register_status_word: 0x0001
register_target_position: 0x0010
register_actual_position: 0x0012

    Modbus RTU 帧格式¶

    请求:   [从站ID(1)] [功能码(1)] [起始地址(2)] [数量(2)] [CRC16(2)]
响应:   [从站ID(1)] [功能码(1)] [字节数(1)] [数据(N)] [CRC16(2)]

FC03（读保持寄存器）:
  请求:   01 03 00 10 00 02 C5 CF
  响应:   01 03 04 03 E8 00 00 XX XX

FC06（写单个寄存器）:
  请求:   01 06 60 40 00 0F XX XX
  响应:   01 06 60 40 00 0F XX XX

FC16（写多个寄存器）:
  请求:   01 10 60 7A 00 02 04 03 E8 00 00 XX XX
  响应:   01 10 60 7A 00 02 XX XX

    故障排除¶

    驱动器无响应¶

    1. 检查接线（A/B 极性、GND 连接）
    2. 确认波特率与驱动器设置匹配
    3. 检查从站地址与驱动器配置一致
    4. 确保已安装终端电阻

    CRC 错误¶

    1. 检查 RS485 总线是否有干扰
    2. 确认电缆长度（9600 波特率下最长约 1200 米）
    3. 尝试降低波特率
    4. 检查设备间接地连接

    位置漂移¶

    1. 确认编码器工作正常
    2. 检查 rotation_distance 与机械结构匹配
    3. 确保驱动器在正确的运行模式

    自定义协议加载失败¶

    1. 确认 Python 文件在 klippy/extras/ 目录下
    2. 检查 protocol_class 路径正确
    3. 确保类继承自 RS485Protocol 或 ModbusRtuProtocol
