    ▼ 🔌 电源与硬件连接 0/5
    电源电压匹配
    确认电源输出电压与主板要求一致（通常为 24V）。
    💡 检查电源标签上的输出电压，与主板规格进行对比。
    主板供电连接
    确保所有电源线正确连接到主板、驱动器和热床（如适用）。
    ⚠️ 检查接线前请务必断电！
    MCU 连接状态
    确认 MCU 已被主机识别。执行 STATUS 命令验证通信。
    STATUS
    步进驱动模块安装
    确认所有步进驱动器已正确安装在插槽中，方向正确。
    CAN 总线连接（如适用）
    如果使用 CAN 总线，确认 CAN 接口已启动且 MCU 可达。
    bash-canbus.sh canscan
    ▼ 🔴 限位开关检查 0/5
    选择限位类型
    选择您使用的限位开关类型：
    微动限位（NC）
    Voron TAP
    光电限位
    电感/电容式
    无限位归位
    限位接线检查
    确认限位开关接线正确。微动限位建议使用 NC（常闭）接法以提高安全性。
    🔴 三线微动限位：必须剪断 5V 线（通常为红色），否则可能烧毁 FLY 主板！
    [stepper_x] endstop_pin: ^!PD9 # ^ = 上拉, ! = 反转（NC 限位）
    QUERY_ENDSTOPS 测试
    执行此命令验证限位状态。未触发时应显示 "open"。
    QUERY_ENDSTOPS
    💡 手动触发每个限位开关，验证其状态变为 "TRIGGERED"。
    限位触发方向
    确认触发逻辑正确：未触发时为 "open"，按下时为 "TRIGGERED"。
    💡 如果状态反转，在 endstop_pin 中添加或删除 !。如果无变化，检查接线并添加 ^ 上拉。
    上拉电阻配置
    确保大多数限位类型（微动、光电等）的 endstop_pin 中包含 ^。
    endstop_pin: ^!PD9 # ^ 启用内部上拉电阻

    ▼ 🌡️ 加热系统检查 0/6
    挤出头温度读数
    确认挤出头温度正常报告且稳定（不会自行上升）。
    🔴 如果温度在未加热时上升，请立即断电！
    热床（如适用）
    检查打印机是否有热床。如有，确认温度读数稳定。
    有热床
    无热床
    M112 紧急停止测试
    发送 M112 命令测试紧急停止功能。验证 Klipper 进入关闭状态。使用 FIRMWARE_RESTART 清除。
    M112 # 等待关闭，然后： FIRMWARE_RESTART
    挤出头加热测试
    设置挤出头到 50°C 并确认温度上升。监控温度曲线。
    M104 S50 # 设置挤出头到 50°C # 等待 30-60 秒，确认温度上升 M104 S0 # 关闭
    💡 如果温度不上升，检查 heater_pin 配置。
    热床加热测试
    设置热床到 50°C 并确认温度上升。
    M140 S50 # 设置热床到 50°C # 等待 30-60 秒，确认温度上升 M140 S0 # 关闭
    PID 校准
    验证加热功能正常后，运行 PID 校准以获得稳定的温度控制。
    PID_CALIBRATE HEATER=extruder TARGET=200 SAVE_CONFIG # 如有热床： PID_CALIBRATE HEATER=heater_bed TARGET=60 SAVE_CONFIG
    ▼ 📏 校准流程 0/5
    Rotation Distance 校准
    校准挤出机旋转距离以确保精确挤出。标记耗材，挤出 50mm，测量实际距离。
    G91 G1 E50 F60 # 以慢速挤出 50mm # 测量实际挤出长度 # new_rotation_distance = old_value * actual_length / 50
    [extruder] rotation_distance: 23.280 # 更新为校准后的值
    Z Offset 校准
    使用纸张法校准喷嘴与热床的距离。调整至纸张有轻微阻力。
    G28 G90 G1 X150 Y150 F3000 # 移动到中心 G1 Z2 F300 # 使用 baby stepping 或调整 Z offset # 机械限位：Z_OFFSET_APPLY_ENDSTOP # 探针：Z_OFFSET_APPLY_PROBE SAVE_CONFIG
    Bed Mesh 校准（如适用）
    如果使用自动调平，运行床面网格校准。
    使用 Bed Mesh
    不使用 Bed Mesh
    BED_MESH_CALIBRATE SAVE_CONFIG
    Input Shaper 校准（如适用）
    如果使用 ADXL345 加速度计，校准输入整形器以减少振纹。
    使用 Input Shaper
    不使用 Input Shaper
    SHAPER_CALIBRATE SAVE_CONFIG
    Pressure Advance 校准（如适用）
    校准压力提前以改善拐角处的挤出控制。
    使用 PA
    不使用 PA
    [extruder] pressure_advance: 0.04 pressure_advance_smooth_time: 0.040
    ▼ 🔧 可选外设检查 0/10
    BLTouch / CR Touch
    自动调平探针。检查部署、收回和 Z 限位功能。
    DEPLOY_PROBE # 确认探针已部署 QUERY_ENDSTOPS # 应显示探针已触发 STOW_PROBE
    Voron TAP
    基于喷嘴的探针。确认探针引脚响应喷嘴接触。
    [probe] pin: ^PC15 x_offset: 0 y_offset: 0 # z_offset: 0 # 通过 PROBE_CALIBRATE 设置
    多 Z 轴
    多个 Z 步进电机（双 Z/三 Z/四 Z）。确认所有 Z 电机正确运动。
    STEPPER_BUZZ STEPPER=stepper_z STEPPER_BUZZ STEPPER=stepper_z1 # STEPPER_BUZZ STEPPER=stepper_z2（如适用） # STEPPER_BUZZ STEPPER=stepper_z3（如适用）
    Z Tilt Adjustment
    多 Z 轴打印机，运行 Z 倾斜调整以校准龙门架水平。
    Z_TILT_ADJUST
    龙门校正 (Skew Correction)
    补偿 XY 平面的机械偏差。
    [skew_correction]
    断料检测
    耗材用尽检测传感器。
    FILAMENT_SENSOR_ENABLE SENSOR=runout # 模拟断料进行测试
    舵机 (Servo)
    舵机电机（如用于笔升降、自动调平等）。
    SET_SERVO SERVO=servo0 ANGLE=0 SET_SERVO SERVO=servo0 ANGLE=90
    RGB LED 灯带
    可寻址 LED 灯带，用于状态指示。
    SET_LED LED=led_print LED=white TRANSMIT=1
    ADXL345 加速度计
    用于输入整形器校准。验证 SPI 连接。
    ACCELEROMETER_QUERY # 应返回数值
    IDEX 双龙门
    独立双挤出，两个打印头。
    SET_DUAL_CARRIAGE CARRIAGE=1 MODE=PRIMARY # 测试独立运动
