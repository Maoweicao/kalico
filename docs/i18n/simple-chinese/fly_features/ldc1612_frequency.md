# LDC1612 外部晶振频率配置

## 概述

增强LDC1612电感传感器驱动器，支持可配置的外部晶振频率和自动传感器分频器计算。这允许使用具有非标准线圈频率的基于LDC1612的传感器。

## 配置

在您的 `[ldc1612]` 或 `[ldc1612 chip_name]` 配置段中：

```ini
[ldc1612]
frequency: 12000000          # 外部晶振频率（Hz），默认12000000
max_sensor_hz: 5000000       # 传感器最大频率（Hz），默认5000000
```

## 参数

| 参数 | 默认值 | 范围 | 说明 |
|-----------|---------|-------|-------------|
| `frequency` | 12000000 | 2000000–40000000 | 外部晶振参考频率 |
| `max_sensor_hz` | 5000000 | 3000000–20000000 | 最大线圈振荡频率 |

## 分频器计算原理

传感器分频器计算公式：

```
sensor_div = ceil(4 × max_sensor_hz / frequency)
```

这确保 `4 × max_sensor_hz < frequency × sensor_div`，满足LDC1612的线圈频率必须小于参考时钟1/4的要求。

## 校准警告

如果LDC1612校准数据包含超过 `max_sensor_hz` 的频率，将显示运行时警告：

```
ldc1612 chip_name: Should set 'max_sensor_hz' to at least <frequency>
```

请相应更新配置并运行 `SAVE_CONFIG`。

## 常见配置

| 传感器 | frequency | max_sensor_hz |
|--------|-----------|---------------|
| BTT Eddy | 12000000 | 5000000 |
| 自定义线圈（8MHz） | 8000000 | 3000000 |
| 自定义线圈（16MHz） | 16000000 | 6000000 |
