# Welcome to the Kalico documentation!

<div class="home-hero" markdown>

![Kalico](logo/kalico-big.png){ .nobg .center-image .main-logo }

Kalico is a community-maintained fork of the Klipper 3D-Printer firmware.
It combines the power of a general purpose computer with one or more
micro-controllers to give you high-resolution, high-performance motion
control with a modern, extensible feature set.

</div>

## What is Kalico?

<div class="grid cards" markdown>

- :material-speedometer: **High-Performance Motion** — Direct stepper control
  with advanced input shaping, pressure advance, and per-axis acceleration
  for fast, precise prints.

- :material-layers-triple: **Extensible** — A plugin system, Python
  G-Code macros, and a growing list of Kalico-specific modules built on
  top of the Klipper architecture.

- :material-connection: **Flexible Hardware** — Supports serial, CAN bus,
  and EtherCAT connected micro-controllers, plus a wide range of drivers,
  sensors, and tools.

- :material-package-variant-closed-check: **Free Software** — Kalico is
  Free Software. Use it, study it, and contribute to its continued
  development.

</div>
