    System Configuration Checklist¶

    This interactive checklist helps you diagnose and verify your Klipper/Kalico printer configuration step by step. Select your printer's kinematics type first, then work through each section.

    System Configuration Checklist

    Step-by-step diagnostic for Klipper/Kalico printer configuration

    ▼ 🔌 Power & Hardware Connection 0/5
    Power Supply Voltage Match
    Verify the PSU output voltage matches your motherboard requirements (typically 24V for most boards).
    💡 Check the label on your PSU and compare with motherboard specs.
    Motherboard Power Connection
    Ensure all power cables are properly connected to the motherboard, drivers, and heated bed (if applicable).
    ⚠️ Always disconnect power before checking wiring!
    MCU Connection Status
    Verify MCU is recognized by the host. Run STATUS command to confirm communication.
    STATUS
    Stepper Drivers Installed
    Verify all stepper drivers are properly seated in their sockets and orientation is correct.
    CAN Bus Connection (if applicable)
    If using CAN bus, verify the CAN interface is up and MCU is reachable.
    bash-canbus.sh canscan
    ▼ 🔴 Endstop Switch Check 0/5
    Select Endstop Type
    Choose the type of endstop switches you are using:
    Microswitch (NC)
    Voron TAP
    Optical
    Inductive/Capacitive
    Sensorless Homing
    Endstop Wiring Check
    Verify endstop wiring is correct. For microswitches, use NC (Normally Closed) for safety.
    🔴 Three-wire microswitches: Cut the 5V wire (usually red) to prevent short circuits on FLY boards!
    [stepper_x] endstop_pin: ^!PD9 # ^ = pullup, ! = invert for NC switch
    QUERY_ENDSTOPS Test
    Run this command to verify endstop states. All should show "open" when not triggered.
    QUERY_ENDSTOPS
    💡 Manually trigger each endstop and verify it shows "TRIGGERED".
    Endstop Trigger Direction
    Verify the trigger logic is correct: "open" when not triggered, "TRIGGERED" when pressed.
    💡 If inverted, add or remove ! in endstop_pin. If no change, check wiring and add ^ for pullup.
    Pullup Resistor Configuration
    Ensure ^ is present in endstop_pin for most endstop types (microswitch, optical, etc.).
    endstop_pin: ^!PD9 # ^ enables internal pullup resistor
    ▼ ⚙️ Motor Direction Calibration 0/4

    Please select your kinematics type above to see motor calibration steps.

    ▼ 🌡️ Heating System Check 0/6
    Extruder Temperature Reading
    Verify the extruder temperature is being reported and is stable (not rising on its own).
    🔴 If temperature is rising without heating command, disconnect power immediately!
    Heated Bed (if applicable)
    Check if your printer has a heated bed. If yes, verify temperature reading is stable.
    Has Heated Bed
    No Heated Bed
    M112 Emergency Stop Test
    Send M112 command to test emergency stop. Verify Klipper enters shutdown state. Clear with FIRMWARE_RESTART.
    M112 # Wait for shutdown, then: FIRMWARE_RESTART
    Extruder Heating Test
    Set extruder to 50°C and verify temperature rises. Monitor the temperature graph.
    M104 S50 # Set extruder to 50°C # Wait 30-60 seconds, verify temp rises M104 S0 # Turn off
    💡 If temp doesn't rise, check heater_pin configuration.
    Heated Bed Heating Test
    Set bed to 50°C and verify temperature rises.
    M140 S50 # Set bed to 50°C # Wait 30-60 seconds, verify temp rises M140 S0 # Turn off
    PID Calibration
    After verifying heating works, run PID calibration for stable temperature control.
    PID_CALIBRATE HEATER=extruder TARGET=200 SAVE_CONFIG # If heated bed: PID_CALIBRATE HEATER=heater_bed TARGET=60 SAVE_CONFIG
    ▼ 📏 Calibration 0/5
    Rotation Distance Calibration
    Calibrate extruder rotation distance for accurate extrusion. Mark filament, extrude 50mm, measure actual distance.
    G91 G1 E50 F60 # Extrude 50mm at slow speed # Measure actual extruded length # new_rotation_distance = old_value * actual_length / 50
    [extruder] rotation_distance: 23.280 # Update with calibrated value
    Z Offset Calibration
    Calibrate nozzle-to-bed distance using paper method. Adjust until paper has slight resistance.
    G28 G90 G1 X150 Y150 F3000 # Move to center G1 Z2 F300 # Use baby stepping or adjust Z offset # For mechanical endstop: Z_OFFSET_APPLY_ENDSTOP # For probe: Z_OFFSET_APPLY_PROBE SAVE_CONFIG
    Bed Mesh Calibration (if applicable)
    If using automatic bed leveling, run bed mesh calibration.
    Uses Bed Mesh
    No Bed Mesh
    BED_MESH_CALIBRATE SAVE_CONFIG
    Input Shaper Calibration (if applicable)
    If using ADXL345 accelerometer, calibrate input shaper to reduce ringing.
    Uses Input Shaper
    No Input Shaper
    SHAPER_CALIBRATE SAVE_CONFIG
    Pressure Advance Calibration (if applicable)
    Calibrate Pressure Advance for better extrusion control at corners.
    Uses PA
    No PA
    [extruder] pressure_advance: 0.04 pressure_advance_smooth_time: 0.040
    ▼ 🔧 Optional Peripherals 0/9
    BLTouch / CR Touch
    Auto bed leveling probe. Check deployment, stowing, and Z endstop function.
    DEPLOY_PROBE # Verify probe deploys QUERY_ENDSTOPS # Should show probe triggered STOW_PROBE
    Voron TAP
    Nozzle-based probe. Verify probe pin responds to nozzle contact.
    [probe] pin: ^PC15 x_offset: 0 y_offset: 0 # z_offset: 0 # Set via PROBE_CALIBRATE
    Multi-Z Axis
    Multiple Z stepper motors (dual/triple/quad Z). Verify all Z motors move correctly.
    STEPPER_BUZZ STEPPER=stepper_z STEPPER_BUZZ STEPPER=stepper_z1 # STEPPER_BUZZ STEPPER=stepper_z2 (if applicable) # STEPPER_BUZZ STEPPER=stepper_z3 (if applicable)
    Z Tilt Adjustment
    For multi-Z printers, run Z tilt adjustment to level the gantry.
    Z_TILT_ADJUST
    Skew Correction
    Compensate for mechanical skew in XY plane.
    [skew_correction]
    Filament Sensor
    Filament runout detection sensor.
    FILAMENT_SENSOR_ENABLE SENSOR=runout # Test by simulating runout
    Servo
    Servo motor (e.g., for pen lift, bed leveling).
    SET_SERVO SERVO=servo0 ANGLE=0 SET_SERVO SERVO=servo0 ANGLE=90
    RGB LED Strip
    Addressable LED strip for status indication.
    SET_LED LED=led_print LED=white TRANSMIT=1
    ADXL345 Accelerometer
    For input shaper calibration. Verify SPI connection.
    ACCELEROMETER_QUERY # Should return values
    IDEX Dual Carriage
    Independent dual extrusion with two print heads.
    SET_DUAL_CARRIAGE CARRIAGE=1 MODE=PRIMARY # Test independent movement
