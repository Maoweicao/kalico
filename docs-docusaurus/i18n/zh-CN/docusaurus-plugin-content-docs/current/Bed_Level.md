# 床面调平

床面调平（有时也称为"床面校准"）对于获得高质量打印至关重要。如果床面没有正确"调平"，可能会导致床面粘附不良、"翘曲"以及整个打印过程中的微妙问题。本文档是使用 Kalico 进行床面调平的指南。

理解床面调平的目标很重要。如果打印机在打印过程中被命令移动到位置 `X0 Y0 Z10`，那么目标是打印机的喷嘴与打印机床面之间的距离正好是 10mm。进一步，如果打印机随后被命令移动到位置 `X50 Z10`，那么目标是喷嘴在整个水平移动过程中与床面保持准确的 10mm 距离。

为了获得良好的打印质量，打印机应该被校准，使 Z 方向距离的精度在大约 25 微米（0.025mm）以内。这是一个很小的距离——明显小于典型人类头发的宽度。这个尺度无法通过"目视"来测量。微妙的影响（如热膨胀）会影响这个尺度上的测量。获得高精度的秘诀是使用可重复的过程，并使用一种利用打印机自身运动系统高精度的调平方法。

## 选择合适的校准机制

不同类型的打印机使用不同的床面调平方法。所有这些最终都依赖于"纸张测试"（如下所述）。但是，特定类型打印机的实际过程在其他文档中描述。

在运行任何这些校准工具之前，请务必运行[配置检查文档](Config_checks.md)中描述的检查。在执行床面调平之前，有必要验证基本的打印机运动。

对于配备"自动 Z 探针"的打印机，请务必按照[探针校准](Probe_Calibrate.md)文档中的说明校准探针。对于 Delta 打印机，请参阅 [Delta 校准](Delta_Calibrate.md)文档。对于配备床面螺钉和传统 Z 限位开关的打印机，请参阅[手动调平](Manual_Level.md)文档。

在校准期间，可能需要将打印机的 Z `position_min` 设置为负数（例如，`position_min = -2`）。打印机即使在校准程序期间也会强制执行边界检查。设置负数允许打印机移动到低于床面标称位置的位置，这可能有助于确定实际床面位置。

## "纸张测试"

主要的床面校准机制是"纸张测试"。它涉及将一张普通的"复印机纸"放在打印机的床面和喷嘴之间，然后命令喷嘴移动到不同的 Z 高度，直到在来回推纸时感觉到少量摩擦。

即使你有"自动 Z 探针"，理解"纸张测试"也很重要。探针本身通常需要校准才能获得良好的结果。探针校准就是使用这种"纸张测试"完成的。

为了执行纸张测试，用剪刀剪一小块矩形纸（例如 5x3 厘米）。纸的厚度通常约为 100 微米（0.100mm）。（纸的确切厚度并不关键。）

纸张测试的第一步是检查打印机的喷嘴和床面。确保喷嘴或床上没有塑料（或其他碎屑）。

**检查喷嘴和床面以确保没有塑料！**

如果你总是在特定的胶带或打印表面上打印，你可以在该胶带/表面就位的情况下执行纸张测试。但是，请注意胶带本身有厚度，不同的胶带（或任何其他打印表面）会影响 Z 测量。务必重新运行纸张测试来测量每种使用的表面类型。

如果喷嘴上有塑料，则加热挤出机并使用金属镊子去除该塑料。在继续纸张测试之前，等待挤出机完全冷却到室温。当喷嘴冷却时，使用金属镊子去除可能渗出的任何塑料。

**始终在喷嘴和床面都处于室温时执行纸张测试！**

当喷嘴加热时，其位置（相对于床面）会因热膨胀而改变。这种热膨胀通常约为 100 微米，大约与一张典型打印纸的厚度相同。热膨胀的确切量并不关键，就像纸的确切厚度并不关键一样。从两者相等的假设开始（有关确定两者差异的方法，请参见下文）。

在室温下校准距离似乎很奇怪，因为目标是在加热时保持一致的距离。但是，如果在校准喷嘴加热时，它往往会将少量熔融塑料转移到纸上，这会改变感觉到的摩擦量。这使得获得良好的校准变得更加困难。在床面/喷嘴热的时候校准也会大大增加烫伤自己的风险。热膨胀的量是稳定的，因此很容易在以后的校准过程中加以考虑。

**使用自动工具确定精确的 Z 高度！**

Kalico 提供了几个辅助脚本（例如 MANUAL_PROBE、Z_ENDSTOP_CALIBRATE、PROBE_CALIBRATE、DELTA_CALIBRATE）。请参阅[上面描述的文档](#choose-the-appropriate-calibration-mechanism)来选择其中一个。

在 OctoPrint 终端窗口中运行适当的命令。该脚本将在 OctoPrint 终端输出中提示用户交互。它将看起来像：
```
Recv: // Starting manual Z probe. Use TESTZ to adjust position.
Recv: // Finish with ACCEPT or ABORT command.
Recv: // Z position: ?????? --> 5.000 <-- ??????
```

喷嘴的当前高度（如打印机当前所理解的）显示在"--\> \<--"之间。右边的数字是最后一次探测尝试的高度，刚好大于当前高度，左边是最后一次探测尝试的高度，小于当前高度（或者 ?????? 如果没有进行过尝试）。

将纸放在喷嘴和床面之间。折叠纸的一个角可能很有用，这样更容易抓住。（来回移动纸时，尽量不要向下推床面。）

![paper-test](/img/paper-test.jpg)

使用 TESTZ 命令请求喷嘴向纸移动更近。例如：
```
TESTZ Z=-.1
```

TESTZ 命令将使喷嘴从当前位置移动一个相对距离。（因此，`Z=-.1` 请求喷嘴向床面移动 0.1mm。）喷嘴停止移动后，来回推纸以检查喷嘴是否与纸接触，并感受摩擦量。继续发出 TESTZ 命令，直到在用纸测试时感觉到少量摩擦。

如果发现太多摩擦，可以使用正 Z 值将喷嘴向上移动。也可以使用 `TESTZ Z=+` 或 `TESTZ Z=-` 来"二分"上次位置——即移动到两个位置之间的中间位置。例如，如果从 TESTZ 命令收到以下提示：
```
Recv: // Z position: 0.130 --> 0.230 <-- 0.280
```
那么 `TESTZ Z=-` 将把喷嘴移动到 Z 位置 0.180（0.130 和 0.230 的中间）。可以使用此功能帮助快速缩小到一致的摩擦。也可以使用 `Z=++` 和 `Z=--` 直接返回到过去的测量——例如，在上述提示后，`TESTZ Z=--` 命令将把喷嘴移动到 Z 位置 0.130。

找到少量摩擦后，运行 ACCEPT 命令：
```
ACCEPT
```
这将接受给定的 Z 高度并继续进行给定的校准工具。

感觉到的摩擦量的确切量并不关键，就像热膨胀量和纸的确切宽度并不关键一样。只需尝试在每次运行测试时获得相同的摩擦量。

如果测试期间出现问题，可以使用 `ABORT` 命令退出校准工具。

## 确定热膨胀

成功执行床面调平后，可以继续计算"热膨胀"、"纸张厚度"和"纸张测试期间感觉到的摩擦量"的综合影响的更精确值。

通常不需要这种计算，因为大多数用户发现简单的"纸张测试"提供了良好的结果。

进行此计算的最简单方法是打印一个四面都有直壁的测试对象。[docs/prints/square.stl](prints/square.stl) 中的大空心正方形可用于此目的。切片对象时，确保切片软件对第一层使用与所有后续层相同的层高和挤出宽度。使用粗略的层高（层高应约为喷嘴直径的 75%），并且不要使用边缘或底座。

打印测试对象，等待其完全冷却，然后将其从床面上取下。检查对象的最低层。（沿着底边用手指或指甲划过也可能有用。）如果发现底层沿对象的所有侧面略微凸出，则表明喷嘴比应有的更靠近床面。可以发出 `SET_GCODE_OFFSET Z=+.010` 命令来增加高度。在后续打印中，可以检查此行为并根据需要进行进一步调整。此类调整通常在 10 微米（0.010mm）范围内。

如果底层持续看起来比后续层窄，则可以使用 SET_GCODE_OFFSET 命令进行负 Z 调整。如果不确定，可以减小 Z 调整，直到打印的底层显示出小的凸起，然后退后直到它消失。

应用所需 Z 调整的最简单方法是创建 START_PRINT g-code 宏，安排切片软件在每次打印开始时调用该宏，并在该宏中添加 SET_GCODE_OFFSET 命令。有关更多详细信息，请参阅[切片软件](Slicers.md)文档。
