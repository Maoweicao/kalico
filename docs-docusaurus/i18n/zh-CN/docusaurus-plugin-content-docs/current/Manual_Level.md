# 手动调平

本文档描述了校准 Z 限位开关和调整热床调平螺丝的工具。

## 校准 Z 限位开关

准确的 Z 限位开关位置对于获得高质量打印至关重要。

但请注意，Z 限位开关本身的精度可能是一个限制因素。如果使用 Trinamic 步进电机驱动器，请考虑启用 [endstop phase](Endstop_Phase.md) 检测以提高开关的精度。

要执行 Z 限位开关校准，首先归位打印机，将打印头移动到 Z 位置至少高于热床五毫米（如果尚未达到），将打印头移动到靠近热床中心的 XY 位置，然后导航到 OctoPrint 终端选项卡并运行：
```
Z_ENDSTOP_CALIBRATE
```
然后按照 ["the paper test"](Bed_Level.md#the-paper-test) 中描述的步骤来确定给定位置处喷嘴与热床之间的实际距离。完成这些步骤后，可以 `ACCEPT` 该位置并使用以下命令将结果保存到配置文件：
```
SAVE_CONFIG
```

最好在 Z 轴远离热床的一端使用 Z 限位开关。（远离热床归位更加稳健，因为这样归位 Z 轴通常是安全的。）但是，如果必须向热床方向归位，建议调整限位开关使其在热床上方一个小距离（例如 0.5mm）处触发。几乎所有限位开关都可以安全地在触发点之外被按下很小的距离。完成此操作后，应该会发现 `Z_ENDSTOP_CALIBRATE` 命令报告 Z position_endstop 为一个小的正值（例如 0.5mm）。在距离热床一定距离时触发限位开关可以降低意外碰撞热床的风险。

某些打印机具有手动调整物理限位开关位置的能力。但是，建议在 Kalico 中通过软件进行 Z 限位开关定位 - 一旦物理位置处于方便的位置，可以通过运行 Z_ENDSTOP_CALIBRATE 或手动更新配置文件中的 Z position_endstop 来进行进一步调整。

## 调整热床调平螺丝

使用热床调平螺丝获得良好热床调平的秘诀是在热床调平过程中利用打印机的高精度运动系统。这是通过将喷嘴命令到每个热床螺丝附近的位置，然后调整该螺丝直到热床与喷嘴保持设定的距离来实现的。Kalico 有一个工具可以帮助完成此操作。要使用该工具，需要指定每个螺丝的 XY 位置。

这是通过创建 `[bed_screws]` 配置部分来完成的。例如，它可能看起来像：
```
[bed_screws]
screw1: 100, 50
screw2: 100, 150
screw3: 150, 100
```

如果热床螺丝在热床下方，则指定螺丝正上方的 XY 位置。如果螺丝在热床外，则指定热床范围内最靠近螺丝的 XY 位置。

配置文件准备好后，运行 `RESTART` 加载该配置，然后可以通过运行以下命令启动工具：
```
BED_SCREWS_ADJUST
```

此工具将把打印机的喷嘴移动到每个螺丝 XY 位置，然后将喷嘴移动到 Z=0 高度。此时，可以使用"纸张测试"来调整喷嘴正下方的热床螺丝。参见 ["the paper test"](Bed_Level.md#the-paper-test) 中描述的信息，但调整热床螺丝而不是命令喷嘴到不同的高度。调整热床螺丝直到来回推纸时感觉到轻微的摩擦力。

一旦调整螺丝直到感觉到轻微的摩擦力，运行 `ACCEPT` 或 `ADJUSTED` 命令。如果热床螺丝需要调整（通常超过约 1/8 圈），则使用 `ADJUSTED` 命令。如果不需要重大调整，则使用 `ACCEPT` 命令。两个命令都会使工具进入下一个螺丝。（当使用 `ADJUSTED` 命令时，工具将安排额外一轮热床螺丝调整；当所有热床螺丝验证后不需要任何重大调整时，工具成功完成。）可以使用 `ABORT` 命令提前退出工具。

当打印机具有平坦的打印表面（如玻璃）和直轨时，此系统效果最好。成功完成热床调平工具后，热床应该可以进行打印了。

### 精细的热床螺丝调整

如果打印机使用三个热床螺丝且所有三个螺丝都在热床下方，则可能可以执行第二次"高精度"热床调平步骤。这是通过将喷嘴命令到热床螺丝调整使热床移动更大距离的位置来实现的。

例如，考虑一个在 A、B 和 C 位置有螺丝的热床：

![bed_screws](/img/bed_screws.svg.png)

对于在 C 位置的热床螺丝进行的每次调整，热床将沿着由其余两个热床螺丝定义的摆锤摆动（此处显示为绿线）。在这种情况下，每次对 C 位置热床螺丝的调整都会使 D 位置的热床移动比 C 位置更多。因此，当喷嘴在 D 位置时，可以进行改进的 C 螺丝调整。

要启用此功能，需要确定额外的喷嘴坐标并将其添加到配置文件。例如，它可能看起来像：
```
[bed_screws]
screw1: 100, 50
screw1_fine_adjust: 0, 0
screw2: 100, 150
screw2_fine_adjust: 300, 300
screw3: 150, 100
screw3_fine_adjust: 0, 100
```

启用此功能后，`BED_SCREWS_ADJUST` 工具将首先提示在每个螺丝位置正上方进行粗略调整，一旦接受，它将提示在额外位置进行精细调整。继续在每个位置使用 `ACCEPT` 和 `ADJUSTED`。

## 使用热床探针调整热床调平螺丝

这是使用热床探针校准热床调平的另一种方法。要使用它，必须有一个 Z 探针（BL Touch、电感式传感器等）。

要启用此功能，需要确定喷嘴坐标使 Z 探针位于螺丝上方，然后将其添加到配置文件。例如，它可能看起来像：

```
[screws_tilt_adjust]
screw1: -5, 30
screw1_name: front left screw
screw2: 155, 30
screw2_name: front right screw
screw3: 155, 190
screw3_name: rear right screw
screw4: -5, 190
screw4_name: rear left screw
horizontal_move_z: 10.
speed: 50.
screw_thread: CW-M3
```

screw1 始终是其他螺丝的参考点，因此系统假定 screw1 处于正确的高度。始终先运行 `G28`，然后运行 `SCREWS_TILT_CALCULATE` - 它应该产生类似以下的输出：
```
Send: G28
Recv: ok
Send: SCREWS_TILT_CALCULATE
Recv: // 01:20 means 1 full turn and 20 minutes, CW=clockwise, CCW=counter-clockwise
Recv: // front left screw (base) : x=-5.0, y=30.0, z=2.48750
Recv: // front right screw : x=155.0, y=30.0, z=2.36000 : adjust CW 01:15
Recv: // rear right screw : y=155.0, y=190.0, z=2.71500 : adjust CCW 00:50
Recv: // read left screw : x=-5.0, y=190.0, z=2.47250 : adjust CW 00:02
Recv: ok
```

这意味着：
- 左前螺丝是参考点，不能更改它。
- 右前螺丝必须顺时针旋转一整圈加四分之一圈
- 右后螺丝必须逆时针旋转 50 分钟
- 左后螺丝必须顺时针旋转 2 分钟（不需要，没关系）

请注意，"分钟"指的是"钟面的分钟"。例如，15 分钟是完整旋转的四分之一。

重复此过程几次，直到获得良好的热床调平 - 通常当所有调整低于 6 分钟时。

如果使用安装在热端侧面的探针（即具有 X 或 Y 偏移量），请注意调整热床倾斜度会使之前在倾斜热床下执行的任何探针校准失效。热床螺丝调整后，请务必运行 [探针校准](Probe_Calibrate.md)。

`MAX_DEVIATION` 参数在使用已保存的热床网格时很有用，用于确保热床调平没有偏离创建网格时的位置太多。例如，可以在加载网格之前在切片器的自定义起始 gcode 中添加 `SCREWS_TILT_CALCULATE MAX_DEVIATION=0.01`。如果超过配置的限制（本示例中为 0.01mm），它将中止打印，给用户调整螺丝并重新开始打印的机会。

`DIRECTION` 参数在您只能朝一个方向旋转热床调整螺丝时很有用。例如，您可能有一些螺丝从最低（或最高）可能位置拧紧开始，只能朝一个方向旋转以抬高（或降低）热床。如果只能顺时针旋转螺丝，请运行 `SCREWS_TILT_CALCULATE DIRECTION=CW`。如果只能逆时针旋转，请运行 `SCREWS_TILT_CALCULATE DIRECTION=CCW`。将选择一个合适的参考点，以便可以通过朝给定方向旋转所有螺丝来调平热床。
