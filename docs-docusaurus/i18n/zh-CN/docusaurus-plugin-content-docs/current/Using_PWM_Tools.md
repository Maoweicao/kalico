# 使用 PWM 工具

本文档介绍如何使用 `pwm_tool` 和一些宏来设置 PWM 控制的激光器或主轴。

## 工作原理

通过重新利用打印头的风扇 PWM 输出，你可以控制激光器或主轴。
如果你使用可切换的打印头（例如 E3D 换头器或 DIY 解决方案），这将非常有用。
通常，cam 工具（如 LaserWeb）可以配置为使用 `M3-M5` 命令，这些命令分别代表 _主轴顺时针转速_ (`M3 S[0-255]`)、_主轴逆时针转速_ (`M4 S[0-255]`) 和 _主轴停止_ (`M5`)。

**警告：** 驱动激光器时，请采取你能想到的所有安全预防措施！二极管激光器通常是反向的。这意味着当 MCU 重新启动时，激光器将在 MCU 重新启动的时间内_完全开启_。为安全起见，建议在激光器通电时_始终_佩戴适当波长的激光护目镜；并在不需要时断开激光器连接。此外，你应该配置安全超时，以便当主机或 MCU 遇到错误时，工具将停止。

有关示例配置，请参见 [config/sample-pwm-tool.cfg](../config/sample-pwm-tool.cfg)。

## 命令

`M3/M4 S<value>` : 设置 PWM 占空比。值在 0 到 255 之间。
`M5` : 将 PWM 输出停止到关闭值。

## LaserWeb 配置

如果你使用 LaserWeb，一个可用的配置如下：

    GCODE START:
        M5            ; 禁用激光器
        G21           ; 设置单位为 mm
        G90           ; 绝对定位
        G0 Z0 F7000   ; 设置非切割速度

    GCODE END:
        M5            ; 禁用激光器
        G91           ; 相对定位
        G0 Z+20 F4000 ;
        G90           ; 绝对定位

    GCODE HOMING:
        M5            ; 禁用激光器
        G28           ; 归零所有轴

    TOOL ON:
        M3 $INTENSITY

    TOOL OFF:
        M5            ; 禁用激光器

    LASER INTENSITY:
        S
