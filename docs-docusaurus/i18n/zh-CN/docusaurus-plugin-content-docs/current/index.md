# 欢迎来到 Kalico 文档！

![](/logo/kalico-big.png)

Kalico 是一个由社区维护的 Klipper 3D 打印机固件分支。
它将通用计算机的强大功能与一个或多个微控制器相结合。请参阅 [功能](Features.md) 文档了解更多关于为什么你应该使用 Kalico 的信息。

要开始使用 Kalico，请先[安装](Installation.md)它。如果你考虑从 Klipper 迁移到 Kalico，请阅读我们专门的[迁移指南](Migrating_from_Klipper.md)。

Kalico 是自由软件。阅读[文档](Overview.md)或在 [GitHub 上查看 Kalico 代码](https://github.com/KalicoCrew/kalico)。

我们依赖[赞助商](Sponsors.md)的慷慨支持。
