# 限位相位

本文档介绍 Kalico 的步进相位调整限位系统。此功能可以提高传统限位开关的精度。当使用具有运行时配置的 Trinamic 步进电机驱动时，此功能最为有用。

典型的限位开关精度约为 100 微米。（每次轴归零时，开关可能略早或略晚触发。）虽然这是一个相对较小的误差，但它可能导致不期望的伪影。特别是，在打印对象的第一层时，这种位置偏差可能很明显。相比之下，典型的步进电机可以获得明显更高的精度。

步进相位调整限位机制可以利用步进电机的精度来提高限位开关的精度。步进电机通过循环一系列相位来移动，直到完成四个"全步"。因此，使用 16 个微步的步进电机将有 64 个相位，当向正方向移动时，它将循环通过相位：0、1、2、... 61、62、63、0、1、2 等。关键的是，当步进电机在线性导轨上的特定位置时，它应始终处于相同的步进相位。因此，当托架触发限位开关时，控制该托架的步进器应始终处于相同的步进电机相位。Kalico 的限位相位系统将步进相位与限位触发相结合，以提高限位的精度。

为了使用此功能，需要能够识别步进电机的相位。如果使用 Trinamic TMC2130、TMC2208、TMC2224 或 TMC2660 驱动在运行时配置模式下（即非独立模式），Kalico 可以从驱动查询步进相位。（如果能可靠地重置步进驱动，也可以在传统步进驱动上使用此系统——详见下文。）

## 校准限位相位

如果使用具有运行时配置的 Trinamic 步进电机驱动，则可以使用 ENDSTOP_PHASE_CALIBRATE 命令校准限位相位。首先将以下内容添加到配置文件：
```
[endstop_phase]
```

然后重启打印机并运行 `G28` 命令，后跟 `ENDSTOP_PHASE_CALIBRATE` 命令。然后将工具头移动到新位置并再次运行 `G28`。尝试将工具头移动到多个不同位置，并从每个位置重新运行 `G28`。至少运行五次 `G28` 命令。

执行上述操作后，`ENDSTOP_PHASE_CALIBRATE` 命令通常会报告步进器的相同（或几乎相同）相位。可以将此相位保存在配置文件中，以便所有未来的 G28 命令使用该相位。（因此，在未来的归零操作中，即使限位开关略早或略晚触发，Kalico 也将获得相同的位置。）

要保存特定步进电机的限位相位，运行类似以下命令：
```
ENDSTOP_PHASE_CALIBRATE STEPPER=stepper_z
```

对所有要保存的步进器运行上述命令。通常，这用于笛卡尔和 corexy 打印机的 stepper_z，以及 delta 打印机的 stepper_a、stepper_b 和 stepper_c。最后，运行以下命令以使用数据更新配置文件：
```
SAVE_CONFIG
```

### 附加说明

* 此功能在 delta 打印机和笛卡尔/corexy 打印机的 Z 限位上最为有用。可以在笛卡尔打印机的 XY 限位上使用此功能，但这不太有用，因为 X/Y 限位位置的轻微误差不太可能影响打印质量。不能在 corexy 打印机的 XY 限位上使用此功能（因为 XY 位置不由 corexy 运动学上的单个步进器决定）。不能在使用"probe:z_virtual_endstop"Z 限位的打印机上使用此功能（因为只有当限位位于导轨上的静态位置时，步进相位才稳定）。

* 校准限位相位后，如果之后移动或调整了限位，则需要重新校准限位。从配置文件中删除校准数据并重新运行上述步骤。

* 为了使用此系统，限位必须足够精确，以在两个"全步"内识别步进位置。因此，例如，如果步进器使用 16 个微步，步距为 0.005mm，则限位必须至少具有 0.160mm 的精度。如果收到"Endstop stepper_z incorrect phase"类型的错误消息，可能是由于限位不够精确。如果重新校准没有帮助，请通过从配置文件中删除它们来禁用限位相位调整。

* 如果你使用传统的（非 Trinamic）步进电机驱动配合传统步进控制的 Z 轴（如笛卡尔或 corexy 打印机），也可以使用此系统来安排每个打印层在"全步"边界上执行。要启用此功能，请确保 G-Code 切片软件配置了"全步"倍数的层高，在 endstop_phase 配置节中手动启用 endstop_align_zero 选项（有关更多详细信息，请参阅[配置参考](Config_Reference.md#endstop_phase)），然后重新调平床面螺钉。

* 可以将此系统与传统的（非 Trinamic）步进电机驱动一起使用。但是，这样做需要确保每次微控制器重置时步进电机驱动也被重置。（如果两者始终一起重置，Kalico 可以通过跟踪它命令步进器移动的总步数来确定步进相位。）目前，唯一可靠的方法是微控制器和步进电机驱动都仅由 USB 供电，并且 USB 电源由运行在 Raspberry Pi 上的主机提供。在这种情况下，可以指定具有"restart_method: rpi_usb"的 mcu 配置——该选项将安排微控制器始终通过 USB 电源重置重置，这将安排微控制器和步进电机驱动一起重置。如果使用此机制，则需要手动配置"trigger_phase"配置节（有关详细信息，请参阅[配置参考](Config_Reference.md#endstop_phase)）。
