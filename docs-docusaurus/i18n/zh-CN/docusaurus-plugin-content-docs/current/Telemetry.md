# Kalico 遥测

Kalico 包含一个可选的遥测系统，用于收集有关你的打印机设置的匿名信息。本文档介绍了什么是遥测、收集了哪些数据、如何使用以及如何控制它。

## 什么是遥测？

遥测是收集匿名使用数据，帮助 Kalico 项目了解用户如何使用该软件。这些信息对于以下方面非常有价值：

- 了解哪些功能最常被使用
- 确定哪些打印机配置受欢迎
- 确定开发工作的优先级
- 提高与不同硬件设置的兼容性
- 为未来的开发做出明智的决策

## 仅限选择加入

Kalico 的遥测系统**严格限于选择加入**。当你第一次运行 Kalico 时，系统会提示你启用或禁用遥测。在你明确启用之前，不会收集任何数据。

## 收集了哪些数据

Kalico 遥测收集以下匿名信息：

### 机器标识
- 唯一的机器 ID（来自 `/etc/machine-id` 或存储在 `.machine-id` 中的生成 UUID）
- 此 ID 用于避免重复计算同一台机器，但无法追溯到你

### 系统信息
- 硬件架构（例如 `x86_64`、`arm64`）
- 来自 `/etc/os-release` 的操作系统信息（发行版名称、版本）
- Python 版本
- CPU 信息（仅型号名称）

### Kalico 软件信息
- Kalico 版本号
- Git 分支名称
- Git 远程 URL

### 配置信息
- **仅配置中的节和选项名称**
- 不收集实际的配置值
- 例如：系统知道你有一个包含 `max_velocity` 等选项的 `[printer]` 节，但不知道你设置的值

### 已启用的对象
- 所有已启用的 Kalico 模块和插件列表
- 这有助于了解正在使用哪些功能

## 不收集的内容

Kalico 遥测**不会**收集：

- 个人信息（姓名、电子邮件、IP 地址）
- 实际的配置值或参数
- 打印机日志或性能数据
- G-code 文件或打印历史
- 任何可能识别你个人身份的信息

## 如何控制遥测

### 查看你的遥测数据

你可以使用 `TELEMETRY_EXAMPLE` G-code 命令来查看将发送的确切数据。这将在你的配置文件夹中保存一个名为 `telemetry.json` 的文件，其中包含将提交的确切数据。

### 启用遥测

如果你想通过共享匿名使用数据来帮助改进 Kalico：

1. 运行 `ENABLE_TELEMETRY` G-code 命令
2. 运行 `SAVE_CONFIG` 保存设置并重启打印机

### 禁用遥测

如果你不想共享遥测数据：

1. 运行 `DISABLE_TELEMETRY` G-code 命令
2. 运行 `SAVE_CONFIG` 保存设置并重启打印机

## 数据处理

- 所有遥测数据发送到 `https://telemetry.kalico.gg/collect`
- 数据通过 HTTPS 安全传输
- 数据以匿名方式存储并汇总用于统计目的
- 单台机器的数据不会与第三方共享

## 配置

可以在 `printer.cfg` 文件中配置遥测：

```
[telemetry]
enabled: True   # 设置为 False 以禁用遥测
```
