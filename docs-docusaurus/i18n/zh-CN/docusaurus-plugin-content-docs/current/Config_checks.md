# 配置检查

本文档提供了一系列步骤来帮助确认 Kalico printer.cfg 文件中的引脚设置。在按照[安装文档](Installation.md)中的步骤操作后，运行这些步骤是个好主意。

在本指南期间，可能需要对 Kalico 配置文件进行更改。务必在每次更改配置文件后发出 RESTART 命令，以确保更改生效（在 OctoPrint 终端选项卡中键入"restart"，然后单击"发送"）。在每次 RESTART 后发出 STATUS 命令以验证配置文件是否成功加载也是个好主意。

## 验证温度

首先验证温度是否正确报告。导航到用户界面中的温度图部分。验证喷嘴和床面（如果适用）的温度是否存在且未增加。如果温度在增加，请断开打印机电源。如果温度不准确，请检查喷嘴和/或床面的"sensor_type"和"sensor_pin"设置。

## 验证 M112

导航到命令控制台，在终端框中发出 M112 命令。此命令请求 Kalico 进入"关闭"状态。它将导致显示错误，可以在命令控制台中使用 FIRMWARE_RESTART 命令清除。OctoPrint 也需要重新连接。然后导航到温度图部分，验证温度继续更新且温度未增加。如果温度在增加，请断开打印机电源。

## 验证加热器

导航到温度图部分，在挤出机/工具温度框中键入 50 然后按回车。图中的挤出机温度应开始增加（大约 30 秒内）。然后转到挤出机温度下拉框并选择"关闭"。几分钟后，温度应开始返回其初始室温值。如果温度未增加，请验证配置中的"heater_pin"设置。

如果打印机有加热床，请对床面再次执行上述测试。

## 验证步进电机使能引脚

验证所有打印机轴可以手动自由移动（步进电机已禁用）。如果不能，发出 M84 命令禁用电机。如果任何轴仍然不能自由移动，请验证给定轴的步进"enable_pin"配置。在大多数通用步进电机驱动上，电机使能引脚是"低电平有效"，因此使能引脚前应有"!"（例如，"enable_pin: !PA1"）。

## 验证限位开关

手动移动所有打印机轴，使它们都不与限位开关接触。通过命令控制台发送 QUERY_ENDSTOPS 命令。它应响应所有已配置限位开关的当前状态，并且它们都应报告"open"状态。对于每个限位开关，在手动触发限位开关时重新运行 QUERY_ENDSTOPS 命令。QUERY_ENDSTOPS 命令应将限位开关报告为"TRIGGERED"。

如果限位开关看起来反转（触发时报告"open"，反之亦然），则在引脚定义中添加"!"（例如，"endstop_pin: ^!PA2"），或者如果已有"!"则移除它。

如果限位开关根本没有变化，则通常表示限位开关连接到了不同的引脚。但是，它也可能需要更改引脚的上拉设置（endstop_pin 名称开头的'^'——大多数打印机将使用上拉电阻，并且应存在'^'）。

## 验证步进电机

使用 STEPPER_BUZZ 命令验证每个步进电机的连接性。首先手动将给定轴定位到中间点，然后在命令控制台中运行 `STEPPER_BUZZ STEPPER=stepper_x`。STEPPER_BUZZ 命令将使给定步进器向正方向移动一毫米，然后返回其起始位置。（如果限位开关定义在 position_endstop=0，则在每次移动开始时，步进器将远离限位开关。）它将执行此振荡十次。

如果步进器根本没有移动，请验证步进器的"enable_pin"和"step_pin"设置。如果步进电机移动但未返回其原始位置，请验证"dir_pin"设置。如果步进电机以不正确的方向振荡，则通常表示该轴的"dir_pin"需要反转。这通过在打印机配置文件中的"dir_pin"添加'!'来完成（如果已有则移除）。如果电机移动明显多于或少于一毫米，请验证"rotation_distance"设置。

对配置文件中定义的每个步进电机运行上述测试。（将 STEPPER_BUZZ 命令的 STEPPER 参数设置为要测试的配置节的名称。）如果挤出机中没有耗材，则可以使用 STEPPER_BUZZ 验证挤出机电机连接性（使用 STEPPER=extruder）。否则，最好单独测试挤出机电机（参见下一节）。

验证所有限位开关并验证所有步进电机后，应测试归零机制。发出 G28 命令归零所有轴。如果未正确归零，请断开打印机电源。如有必要，重新运行限位开关和步进电机验证步骤。

## 验证挤出机电机

要测试挤出机电机，需要将挤出机加热到打印温度。导航到温度图部分，从温度下拉框中选择目标温度（或手动输入适当的温度）。等待打印机达到所需温度。然后导航到命令控制台并单击"挤出"按钮。验证挤出机电机是否以正确的方向转动。如果没有，请参阅上一节中的故障排除提示，确认挤出机的"enable_pin"、"step_pin"和"dir_pin"设置。

## 校准 PID 设置

Kalico 支持挤出机和床面加热器的 [PID 控制](https://en.wikipedia.org/wiki/PID_controller)。为了使用此控制机制，需要在每台打印机上校准 PID 设置（在其他固件或示例配置文件中找到的 PID 设置通常效果不佳）。

要校准挤出机，导航到命令控制台并运行 PID_CALIBRATE 命令。例如：`PID_CALIBRATE HEATER=extruder TARGET=170`

调整测试完成后，运行 `SAVE_CONFIG` 以更新 printer.cfg 文件中的新 PID 设置。

如果打印机有加热床且支持 PWM（脉宽调制）驱动，则建议对床面使用 PID 控制。（当床面加热器使用 PID 算法控制时，它可能每秒开关十次，这可能不适用于使用机械开关的加热器。）典型的床面 PID 校准命令是：`PID_CALIBRATE HEATER=heater_bed TARGET=60`
