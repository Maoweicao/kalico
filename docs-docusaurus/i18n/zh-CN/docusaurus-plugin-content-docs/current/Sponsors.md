# 赞助商

Kalico 是一个社区驱动的开源项目，免费使用（如"免费啤酒"）。
虽然我们目前还没有官方赞助商，但我们非常感谢社区的慷慨支持。
每一份贡献都帮助我们持续改进 Kalico，为大家服务。

如果你想支持 Kalico，非常欢迎通过 Ko-Fi 捐赠：
👉 [https://ko-fi.com/kalicocrew](https://ko-fi.com/kalicocrew)
